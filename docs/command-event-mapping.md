# 命令‑事件关联对照表
项目：CampusOverflow校园问答平台
实验三 事件风暴‑Process Modeling流程建模
成员：成员三

## 角色列表
| 角色 | 角色说明 |
| ---- | ---- |
| 校园用户 | 在校学生，可以注册账号、浏览问题、发布提问、提交回答、收藏问题、采纳最佳回答 |

## 外部依赖系统
| 外部系统名称 | 依赖场景 |
| ---- | ---- |
| 校园OAuth统一认证系统 | 用户注册账号时，对接校园身份，完成身份校验 |
| 邮件通知服务 | 发布问题、提交回答、回答被采纳时，给相关用户发送通知邮件 |

## 命令‑事件映射表
> 说明：查询类操作浏览问题列表不产生领域事件。
| 命令编号 | 命令名称（蓝色卡片） | 触发角色 | 对应产生领域事件 | 关联外部系统 |
| ---- | ---- | ---- | ---- | ---- |
| C01 | 注册账号 | 校园用户 | 账号已注册 | 校园OAuth统一认证系统 |
| C02 | 浏览问题列表 | 校园用户 | （查询操作，无领域事件） | 无 |
| C03 | 发布问题 | 校园用户 | 问题已发布 | 邮件通知服务 |
| C04 | 提交回答 | 校园用户 | 回答已提交 | 邮件通知服务 |
| C05 | 收藏问题 | 校园用户 | 问题已收藏 | 无 |
| C06 | 采纳回答 | 校园用户 | 回答被采纳 | 邮件通知服务 |
