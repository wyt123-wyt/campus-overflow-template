# CampusOverflow 团队章程 v1.0

> 生效日期：2026 年 10 月
> 签署人：王渊桐、解雨暄、汤婉莹、张轩、秦子龙

## 1. 团队价值观

1. 小步提交，不憋大招——一天至少推一次分支
2. PR 不过夜——当天提的 PR 当天有人 Review
3. 报错不丢人，卡住两小时就喊人
4. main 分支是命根子，谁直推谁请喝奶茶

## 2. 沟通约定

- 主沟通工具：QQ群
- @了才必须回，没@的消息 24 小时内回
- 紧急事（编译炸了、明天要交作业）直接打电话
- 每日站会：中午 12:30，每人说三句——昨天干了啥、今天干啥、卡在哪

## 3. 开发规约

- 分支命名：feature/事项、fix/bug、hotfix/紧急
- commit 前缀：feat: 新功能 / fix: 修bug / docs: 文档 / refactor: 重构
- main 分支禁止直推，必须走 PR + 至少 1 人 Approve
- 代码风格跟着已有模块写，别自己瞎调格式

## 4. DoD（完成定义）

任务算"做完"，必须同时满足：

- [ ] 本地能跑通，自己测过一遍
- [ ] PR 发出来，至少 1 个队友 Approve（写 LGTM）
- [ ] 合并到 main 后构建没红
- [ ] 看板卡片移到 Done 列
