# PO MVP切片与优先级判定文档
## 1. 用户故事地图横轴
注册 → 浏览问题 → 查看详情 → 发布问题 → 提交回答 → 互动点赞 → 用户成长

## 2. Sprint1 Walking Skeleton（MVP走骨架）
本轮只保留能完成核心闭环的最小链路：
账号登录 → 浏览问题列表 → 查看问题详情 → 发布问题 → 提交回答
> 暂不纳入：点赞、收藏、积分、个人中心等增值功能，保证骨架可跑、工作量可控。

## 3. 价值-成本优先级划分
 高价值、低成本（纳入Sprint1）
ST01 用户登录
ST02 浏览全部问题列表
ST03 查看单条问题详情
ST04 用户发布新问题
ST05 针对问题提交回答

 高价值、高成本（延后，不进Sprint1）
ST06 回答点赞
ST07 收藏问题
ST08 我的个人主页

 低价值（放到后续Sprint）
ST09 消息通知
ST10 用户等级成长

## 4. Sprint1入选结论
Sprint1 选定 ST01~ST05，作为本次开发范围。
